# 0008 Názvy rep: `proavus` a `proavus-<rodina>`

- **Stav:** přijato (2026-10-20)
- **Původně:** R12

## Kontext

Název rodinného repa má říkat, čí rodokmen obsahuje; název popisující viditelnost (`-private`) je matoucí.

## Rozhodnutí

Framework se jmenuje `proavus`; rodinná repa `proavus-<rodina>` (např. `proavus-novak`), výchozí název v šabloně `proavus-family`. Organizace `proavus` zatím nevzniká.

## Důsledky

`/init` nabídne název podle vzoru. Jméno rodiny nikdy není v názvu frameworku.
